# RP 포맷터

네이버 카페 RP 텍스트를 복사하면 캐릭터 이미지와 대사가 정리된 형식으로 출력되는 웹페이지입니다.

## 기능

- **실시간 미리보기**: 텍스트를 붙여넣으면 바로 포맷팅된 결과 확인
- **캐릭터 관리**: 캐릭터별 이미지 등록 (URL 입력 또는 파일 업로드)
- **URL 공유**: 링크만 있으면 어디서든 같은 내용을 볼 수 있음
- **자동 저장**: 캐릭터 정보는 브라우저에 자동 저장

## 로컬 테스트

```bash
cd nonova
python -m http.server 8080
```

브라우저에서 `http://localhost:8080` 접속

## 무료 호스팅 배포 방법

### 방법 1: Vercel (추천)

1. [Vercel](https://vercel.com) 가입 (GitHub 계정으로 가능)
2. 프로젝트 폴더를 GitHub에 업로드
3. Vercel 대시보드에서 "New Project" 클릭
4. GitHub 저장소 연결
5. "Deploy" 클릭 → 완료!

### 방법 2: Netlify

1. [Netlify](https://netlify.com) 가입
2. 대시보드에서 폴더를 드래그 앤 드롭으로 업로드
3. 자동으로 URL 생성됨

### 방법 3: GitHub Pages

1. GitHub에 저장소 생성
2. 파일들 업로드
3. Settings > Pages > Source에서 "main" 브랜치 선택
4. 몇 분 후 URL 생성됨

## 사용 방법

1. 네이버 카페에서 RP 댓글을 복사
2. 왼쪽 입력창에 붙여넣기
3. 오른쪽에서 포맷팅된 결과 확인
4. "캐릭터 관리" 버튼으로 이미지 등록
5. "공유 링크 생성" 버튼으로 URL 복사 → 공유

## 지원하는 입력 형식

```
프로필	에르빈 1
2021.11.20. 02:51답글
(대사 내용...)

프로필
노바 1작성자
2021.11.20. 03:08답글수정|삭제
(대사 내용...)
```
